# Базовая концепция 

## Класс ПМИ (PMI). Основной класс, представляющий собой модель документации ПМИ

имеет основной метод
**getDocx()** - для выдачи сформированного отчета ПМИ в формате docx - обязательный метод!!!
**getLatex()** - при наличии свободного времени и желания метод для выдачи отчета в формате LAtex

Инициализация объекта класса PMI
Объект класса ПМИ инициализируется путем к каталогу с режимами в формате xlsx. _pmi=PMI(path_to_modes)
при этом каждый режим создается в виде модели (класс Режим class Mode)
в пространстве модели ПМИ объекты класса Mode существуют в списке объектов _modes

## Класс Режим (Mode). Вспомогательный класс для описания режимов (в формате xlsx)
методы класса
_load_mode для загрузки и парсинга режима в словарь
_validate_mode нужен ли??


## Класс Режимы (Modes). Возможно придется использовать для создания общих методов для анализа режимов
содержит методы
 _add_mode для добавления режима в список
