ДЛЯ ЗАПУСКА НЕОБХОДИМО НАЛИЧИЕ СЛЕДУЮЩЕГО
1. В корневой папке файл с описанием функций description.json
2. В папке ПМИ - файлы описания режимов xlsx для каждого раздела в своей папке (заканчиваться на _modes!).
3. В папке ПМИ файл _assembly.ini - для сборки ПМИ
4. Файл template.docx - шаблон основного файла ПМИ
5. Файл template_apx.docx - шаблон Приложения ПМИ
6. Папка fsu в корне - с необходимыми ПОДГОТОВЛЕННЫМИ описаниями ФБ ОП Чебоксары для тех ФБ, что в assembly.ini указаны
